Custom website audit

We review websites and web services built from scratch or on frameworks — code, backend and configuration — and find vulnerabilities before anyone exploits them.

What’s included

  • OWASP Top 10 checks: injections, XSS, CSRF
  • Authentication, sessions and access to other users’ data (IDOR)
  • Forms, file uploads, APIs and payment flows
  • Server configuration, HTTPS and security headers
Timeline: from 3 days

Telegram bot audit

We check whether someone could steal the token, bypass payments, get into the admin panel or access user data.

What’s included

  • Token storage and webhook protection
  • Admin permissions and access to commands
  • Payment tampering and bypasses
  • Protection from flooding, spam and personal data leaks
Timeline: from 3 days

Telegram Mini App audit

We review the whole stack: the Mini App UI, the bot and the backend — with a focus on authentication and payments.

What’s included

  • Server-side initData signature validation
  • API protection, CORS and Content Security Policy
  • Client-side tampering with user data and prices
  • Secure data exchange between the Mini App, bot and server
Timeline: from 3 days
